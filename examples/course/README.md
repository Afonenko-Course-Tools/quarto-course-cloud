# Пример облачного задания

Пример показывает задание из двух шагов на двух виртуальных машинах: один шаг использует внешний файл проверки, второй — код внутри QMD. Нужны актуальные Quarto, CUE и ядро курса. CI проверяет каналы Quarto `release` и `pre-release`.

Выполните из каталога этого примера:

```sh
quarto add ../../../quarto-course
quarto add ../..
quarto render
quarto preview
```

Пример ожидает `quarto-course` рядом с репозиторием адаптера. При установке ядра из GitHub добавьте каталог владельца в пути `project.pre-render` и `project.post-render`. Команда `quarto add ../..` устанавливает адаптер из корня этого репозитория; её повторяют после изменения исходников.

При сборке проверяются разметка, связи, объявления машин и существование файлов. Команды из заданий не исполняются. Установленные расширения и результаты сборки исключены из Git; QMD и авторские ресурсы хранятся в репозитории.
