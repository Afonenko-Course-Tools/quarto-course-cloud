# Пример облачного задания

Пример показывает задание из двух шагов на двух виртуальных машинах: один шаг использует внешний файл проверки, второй — код внутри QMD. Нужны актуальные Quarto, CUE и ядро Course Core. CI проверяет каналы Quarto `release` и `pre-release`.

Выполните из каталога этого примера:

```sh
quarto add AfonenkoA/programming-course-core-specification
quarto add ../..
quarto render
quarto preview
```

Вместо адреса GitHub можно указать путь к локальному репозиторию ядра. Команда `quarto add ../..` устанавливает адаптер из корня этого репозитория; её повторяют после изменения исходников.

При сборке проверяются разметка, связи, объявления машин и существование файлов. Команды из заданий не исполняются. Установленные расширения и результаты сборки исключены из Git; QMD и авторские ресурсы хранятся в репозитории.
